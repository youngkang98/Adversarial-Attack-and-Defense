# attacks/

Adversarial attack implementations covering three families:

| Subdirectory | Attack type | Description |
|---|---|---|
| `uap/` | Universal Adversarial Perturbations | Single perturbation that fools a model on most inputs |
| `backdoor/` | Backdoor / trojan attacks | Poison training data to embed a hidden trigger |
| `covid_uap/` | COVID-Net UAP | UAP attacks evaluated on COVID-Net using IBM ART |

See each subdirectory's README for dataset-to-script mappings and run instructions.
